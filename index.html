⚙️ Первый запуск

Для синхронизации между двумя людьми нужен бесплатный JSONBin.io аккаунт. Это займёт 2 минуты.

Первый человек: создаёт Bin, получает Bin ID, отправляет его второму.
Второй человек: вводит тот же API Key и Bin ID — и оба видят один список.
  1. Зайди на jsonbin.io → Sign Up
  2. После входа → API Keys → скопируй Secret Key
  3. Вставь ниже и нажми «Подключить»
Хранится только в этом браузере
Второй человек вводит тот же Bin ID что и первый
